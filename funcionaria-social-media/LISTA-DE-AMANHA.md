# Lista de amanhã · Funcionária Social Media

Faça na ordem. Anote o resultado de cada teste (funcionou / falhou / o que apareceu).

## 1. Preparar (15 min)
- [ ] Abrir o **chatgpt.com** digitando o endereço direto (nunca por anúncio de busca).
- [ ] Baixar do GitHub (**Raw** → `Ctrl + S`) estes arquivos, sem "(1)" no nome: `01`, `05`, `06`, `07`, `08`, `09`, `10`.
- [ ] Abrir o projeto com **memória só do projeto**.
- [ ] Campo de **instruções**: apagar tudo e colar o `01` a partir de `## QUEM VOCÊ É`. Se não couber, usar o `01b`.
- [ ] Aba **Fontes**: remover arquivos antigos e enviar `05`, `06`, `07`, `08`, `09`, `10`. Esperar o carregamento terminar.
- [ ] Anotar: qual **plano** do ChatGPT você usa.

## 2. Testes de texto
- [ ] `menu` → apareceu a lista com **13 opções**?
- [ ] `1` → calendário da semana. Tabela, só Reels e Stories, sem inventar produtos, termina com "Próximo passo:" sem pergunta?
- [ ] `5` → legenda de venda. Disse "Modo Copywriter ativado" e marcou o que faltava?
- [ ] `9` → roteiro de vídeo para o avatar.
- [ ] `10` → cole uma mensagem de cliente. Apareceram resposta curta e completa? Marcou [CONFIRMAR] onde faltava informação?
- [ ] `11` → ideias de anúncio. Disse "vale testar" e não prometeu resultado?
- [ ] `12` → colar números de exemplo. Ela avisou se a amostra era pequena?
- [ ] `13` → conversa de sócia. Deu 3 prioridades e o que não fazer?

## 3. Testes de honestidade
- [ ] "Qual é o melhor horário para postar?" → mandou conferir nos insights?
- [ ] "Qual trend está em alta hoje?" → avisou que pode estar desatualizada?
- [ ] "Você vai postar por mim?" → disse que não posta sozinha?
- [ ] Perguntar o preço de algo que não está no briefing → pediu em vez de inventar?

## 4. Testes de imagem (o mais importante)
- [ ] `4` → carrossel completo. Estilo parecido com o que você aprovou (fundo realista, objeto 3D, pílula, ícones)?
- [ ] Cada slide é **imagem separada**? Clique num quadrado e baixe um por um.
- [ ] Texto **sem erro de português**? Contador em todos?
- [ ] Sem logo de terceiros (Canva) no mockup?
- [ ] `8` → pacote da semana, tudo de uma vez, sem perguntas?
- [ ] Testar um **nicho diferente** (ex.: terapia). O estilo se manteve?
- [ ] Anotar quantas imagens foram geradas e se apareceu aviso de limite.

## 5. Funções a descobrir
- [ ] O ChatGPT tem **tarefas agendadas**? Teste: "agende esta tarefa toda segunda às 8h". Só prometa se funcionar de ponta a ponta.
- [ ] Como ativar **memória só do projeto**: anotar o caminho exato e tirar print (vai para o guia).

## 6. Conteúdo de saúde
- [ ] Pedir a um **dentista** (ou ao profissional do nicho) que revise os textos dos carrosséis antes de postar.
- [ ] Conferir as regras de publicidade do conselho profissional do nicho.

## 7. Se tudo funcionar, próximos passos do produto
- [ ] Preencher o **guia de instalação** (eu preparo, você coloca os prints).
- [ ] Escrever a seção **"O que você precisa para usar"** (plano do ChatGPT, limite de imagens, o que ela não faz).
- [ ] Definir o **preço** (R$ 97 é hipótese) e o que entra no produto.
- [ ] Gravar a **VSL** só com o que foi testado. Evitar "trabalha sozinha", "24 horas", "posta por você".
- [ ] Escolher a plataforma (Hotmart, Kiwify ou outra), conferir taxas e regras.
- [ ] Preparar a **versão em espanhol** do kit.
- [ ] Tornar **privado** o repositório `funcion-ria-IA` ou apagar.

## O que NÃO prometer na VSL
- Postar ou agendar sozinha, ver os números da conta, funcionar 24 horas sozinha.
- Resultados de venda, seguidores ou saúde.
- "De graça", a menos que você confirme que funciona no plano gratuito.
